Privacy policy

How UMiX Convert handles browser-based file tools and information connected with this website.

Last updated: October 13, 2026

Overview

UMiX Convert is a static website offering browser-based file conversion and productivity tools. This policy explains what the current implementation does and what information may be handled when you use the website.

Files and browser-based processing

The converter tools currently read selected files in your browser using JavaScript and local vendor libraries. The tool pages state when processing is local. The current implementation does not upload selected files to a UMiX Convert application server, and it does not provide a UMiX account or server-side file storage.

During processing, a browser may hold file data, previews, and generated results temporarily in memory. Some tools create temporary browser object URLs for previews or downloads. These are released by the page where supported, and downloaded files remain wherever you choose to save them on your device. Close the page and manage downloaded files when you no longer need them.

Information the website may receive

When you visit a public website, its hosting, CDN, or security infrastructure may receive ordinary technical request information such as an IP address, date and time, requested path, browser or device details, referrer, and response status. We do not control the exact retention practices of the hosting provider. UMiX Convert does not currently include an account system or a contact form that submits messages to an application database.

Cookies and similar technologies

The current UMiX Convert application does not intentionally set first-party cookies, use localStorage for user accounts, or include a cookie-based analytics system. Your browser may still use its own cache and security mechanisms, and hosting or security services may use essential technical mechanisms to deliver and protect the site.

Analytics, advertising, and third parties

The current project does not include Google Analytics, Google AdSense, or advertising scripts. If advertising or analytics is added later, this policy should be updated before those services are enabled to explain their cookies, similar technologies, and available choices. The site includes local libraries required by particular tools; those libraries support in-browser processing and are not a UMiX Convert file-upload service.

Your choices and privacy questions

You can choose whether to select a file, use a tool, or download a generated result. You can clear browser data and remove downloaded files using your browser and device controls. For privacy questions about UMiX Convert, contact abdulwasiukura@gmail.com.

Policy updates

We may update this policy when the website, tools, hosting arrangements, analytics, or advertising practices change. The date at the top indicates when this version was last updated.

See also our Terms of Use and About UMiX Convert page.
